# SITRAP frontend

Requiere Node 24 LTS y npm. Desde `frontend/`: `npm ci`, `npm run dev`.
Verificación: `npm test` y `npm run build`.

Desarrollo exclusivo en `agente-frontend`. Especificaciones revisión 3 en la raíz.
API prevista: `/api/v1`, mismo origen; Vite redirige a `127.0.0.1:8000`.
No hay backend integrado en esta rama. Estado detallado en `../docs/AVANCE_FRONTEND.md`.
